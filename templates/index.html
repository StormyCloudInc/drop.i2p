POST /api/upload

Upload a file using multipart/form-data.

Parameters:
  • file (required) - The file to upload (max 50MB)
  • expiry - Expiration time: 15m, 1h, 2h, 4h, 12h, 24h, 168h (7 days), 720h (30 days). Default: 24h
  • password - Optional password protection
  • max_downloads - Max download count before auto-delete
  • keep_metadata - Set to "1" to preserve EXIF/GPS data
# Basic upload
curl -X POST -F "file=@/path/to/image.jpg" \
  http://{{.Host}}/api/upload

# With options
curl -X POST \
  -F "file=@/path/to/secret.pdf" \
  -F "expiry=1h" \
  -F "password=mysecret" \
  -F "max_downloads=5" \
  http://{{.Host}}/api/upload
Response: 
{"id":"abc123","url":"/f/abc123","delete_token":"xyz789"}

POST /api/upload/paste

Create a paste using JSON.

JSON Fields:
  • content (required) - The text content
  • language - Syntax highlighting: text, markdown, go, python, javascript, html, css, bash, sql, json. Default: text
  • expiry - Expiration time: 1h, 24h, 168h, 720h. Default: 1h
# Create a paste
curl -X POST \
  -H "Content-Type: application/json" \
  -d '{"content": "print(\"Hello World\")", "language": "python", "expiry": "24h"}' \
  http://{{.Host}}/api/upload/paste
Response: 
{"id":"def456","url":"/p/def456","delete_token":"uvw123"}
